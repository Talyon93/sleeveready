# Game icons

The game-selection icons and WOFF2 files were downloaded from the public CardTrader stylesheet and asset host on 24 September 2026.

- Source page: https://www.cardtrader.com/en/games/lorcana/categories
- Source stylesheet: https://www.cardtrader.com/assets/application-43dde630ab4745a197a89c38ccd07607063190daa6f979c117f1c448ee332372.css
- Classes used by CardTrader: `ss-mtg`, `ss-pok`, `ss-yug`, `ss-fab`, `ss-dig`, `ss-dbs`, `ss-van`, `ss-op`, `ss-lor`, `ss-swu`, `ss-ua`, `ss-rif`, `ss-gun`, `ss-sor`, `ss-pal`, `ss-cyb` with `ss-game-icon`.

The files are stored locally so the game selector does not depend on third-party requests at runtime. The icons and game marks belong to their respective owners and are used only to identify the corresponding games.
